# Skill: dashboard-update (Wepop)

> [you] = the caller's workspace name. The deployed dashboard is now the delivery board. Do not
> hand-edit docs/index.html; it is regenerated. This skill is really a thin wrapper over task-board.

## Trigger
- "update the dashboard", "refresh the dashboard", "snapshot the dashboard".

## What the dashboard is now
- `docs/index.html` = the GitHub Pages ROOT page = the full five-view BetaCraft board (light mode).
- It is generated by `team/board-render.py`, which also writes `team/board.html` (inline artifact)
  and `docs/board-public.html` (kept so older links resolve).
- The old dark narrative dashboard is retired and archived at `team/legacy-dashboard.html`.

## Pre-read
1. `skills/task-board/SKILL.md` (the board is owned there).
2. `shared/TASK-BOARD.md` (task data).
3. `shared/PROJECT_INDEX.md` (RAG / phase), `shared/HOTSHEET.md` (open / watch / blockers).

## Steps
### Step 1 - Gather current state (decisions, phase, what changed).
### Step 2 - Update the board content: task rows in `shared/TASK-BOARD.md`; the milestone / scope /
  digest view data in `team/board-render.py` (MILESTONES, SCOPE, HORIZON, and the digest strings in
  `team/board-template.html`). Keep it light mode and BetaCraft-branded. Never restyle to dark.
### Step 3 - Regenerate: `python3 team/board-render.py` (writes docs/index.html, docs/board-public.html, team/board.html).
### Step 4 - Show the refreshed board inline as the wepop-task-board artifact. Report what changed, flag for Aakash's review, suggest a name-prefixed commit.

## Never
- Hand-edit docs/index.html or reintroduce the dark narrative dashboard.
- Run git commit / push; restyle to a dark theme or change the BetaCraft branding; em-dash; DENY.
