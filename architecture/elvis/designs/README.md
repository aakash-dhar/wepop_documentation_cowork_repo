# Elvis - design drops

Drop your Wepop design exports here. This is your area (architecture/elvis/), so you can push
straight to it.

## How
1. In Claude Design, open the finished design and Export -> Standalone HTML.
2. Save the .html (and any image assets) into a dated subfolder here, for example:
   `architecture/elvis/designs/2026-08-20_moments/`
3. In GitHub Desktop: Commit, then Push.

## Conventions
- Name folders by date and screen set: `YYYY-MM-DD_short-name`.
- One live version per design. When you push a newer version, the previous one moves to
  `architecture/elvis/_archive/` (Aakash handles that when he logs the drop).
- Keep everything in your own area. Aakash merges anything that affects the shared docs.

Once a drop lands, Aakash runs the design-intake skill to version it, catalog the screens, and
diff it against the last drop.
