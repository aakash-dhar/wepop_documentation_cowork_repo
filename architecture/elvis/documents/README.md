# Elvis - documents

Drop your Wepop documents here: specs, briefs, the reviewed Phase 1 Brief, the Moments spec, and
so on. This is your area, so you can push straight to it.

## How
1. Export from wherever you write them (PDF, Word, or PowerPoint), or write them in a Cowork
   session with this repo open.
2. Save the file with a dated name, for example:
   `architecture/elvis/documents/2026-08-20_phase1-brief-v3.pdf`
3. In GitHub Desktop: Commit, then Push.

Keep documents in your own area. Aakash merges anything that affects the shared record.
